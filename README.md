# 全栈学习笔记
[在线地址](https://blog.eqxph.com/)


## Install

```sh
pnpm i  
```

## Usage

```sh
# start dev server
pnpm docs:dev
# build for production
pnpm docs:build
# preview production build in local
pnpm docs:preview
# update vuepress and theme
pnpm vp-update
```
